**R.A.M.B.O.** (**R**ealistic **A**erodynamics, **M**ass & **B**uoyancy **O**verhaul) is a mod for **Stormworks: Build and Rescue** which improves hydrodynamics and aerodynamics, rebalances component mass and thrust, adds new paintable surfaces and more.

- Get [R.A.M.B.O.](https://steamcommunity.com/id/thales_/myworkshopfiles/?appid=573090)
- Join [Discord](https://discord.gg/DSMWtpKgYH)
- Create [Issues](https://github.com/Thales546/rambo-stormworks/issues) for feedback and suggestions
***
## Key Highlights
- 5 to 10x higher **buoyancy** and fluid mass in enclosed volumes
- Component **mass** rebalance; significantly heavier engine components, weapons, seats, fuel; lighter basic blocks, etc.
- Nerfed propulsion, more realistic **thrust-to-weight** ratios
- Higher airspeed is achievable with less **propulsion**.
- **Aerodynamic** shape is far more important for drag reduction.
- Basic building blocks and a few dozen other components have better buoyancy (aerodynamic) **surfaces** which reflect their shape.
- No new components but stock components are modified with **compatibility** in mind. You can load and run your stock vehicles without voxel or logic mismatch.
- **Cosmetic changes**:
  - New **paintable** surfaces for lots of components such as weapons, control surfaces and engine components,
  - **Editor-only** arrows or indicators for some components such as impeller pumps and catalytic converter,
  - Fixed many **texture z-fighting** by shrinking meshes very slightly (especially for XML-edits),
  - Static **NPC**s on passenger seats/beds via Hat selection,
  - A few **sound** and volume changes.
